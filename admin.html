Полное управление каталогом без сервера

Эта админка работает прямо на статичном хостинге: вы редактируете карточки машин, загружаете фото, сохраняете данные в GitHub, а GitHub Actions автоматически отправляет обновлённый сайт по FTP.

  • Можно создавать, редактировать, удалять и менять порядок карточек автомобилей.
  • Фото загружаются в репозиторий, а каталог хранится в одном JSON-файле, который читает публичный сайт.
  • GitHub token нужен только администратору и используется для записи в репозиторий.

Подключение к GitHub

Для публикации нужен токен с правом записи в `Contents`. Если репозиторий приватный, сначала нажмите «Подключиться к GitHub», чтобы забрать актуальный `catalog.json`.
