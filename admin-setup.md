# Админка каталога и FTP-деплой

## Что уже настроено

- Публичный каталог читает данные из `/data/catalog.json`.
- Админ-панель доступна по адресу `/admin.html`.
- При публикации из админки изменения пишутся в GitHub-репозиторий.
- После пуша в `main` GitHub Actions запускает FTP-деплой на хостинг через `.github/workflows/deploy.yml`.

## Что нужно сделать в GitHub

1. Откройте репозиторий сайта.
2. Перейдите в `Settings` -> `Secrets and variables` -> `Actions`.
3. Добавьте секреты:
   - `FTP_SERVER`
   - `FTP_USERNAME`
   - `FTP_PASSWORD`
   - `FTP_SERVER_DIR` — папка сайта на хостинге, например `/public_html/`
4. Если хостинг использует нестандартный порт или FTPS, добавьте:
   - `FTP_PORT`
   - `FTP_PROTOCOL` — `ftp` или `ftps`

## Что нужно для админки

1. Создайте GitHub token с правами на запись содержимого репозитория (`Contents: Read and write`).
2. Откройте `/admin.html`.
3. Укажите:
   - `Owner` — по умолчанию `Ivan200504`
   - `Repo` — по умолчанию `cars`
   - `Branch`
   - `Путь к JSON каталога` — по умолчанию `data/catalog.json`
   - `Папка для фото` — по умолчанию `assets/catalog`
   - `GitHub token`
4. Нажмите `Подключиться к GitHub`.
5. Отредактируйте каталог и нажмите `Опубликовать каталог`.

## Как работает публикация

1. Админка загружает новые фото в папку `assets/catalog`.
2. Админка обновляет файл `data/catalog.json`.
3. GitHub Actions ловит пуш в `main`.
4. Workflow по FTP синхронизирует сайт с хостингом.

## Важно

- Токен не должен быть публичным. Админка хранит его только в браузере администратора, если включить чекбокс сохранения.
- Если открывать сайт двойным кликом как `file://`, загрузка `catalog.json` может блокироваться браузером. Для локальной проверки используйте любой HTTP-сервер.
